# Contributing to Actual Pocket

Actual Pocket is a personal fork of [Actual Budget](https://github.com/actualbudget/actual), maintained by **Danilo Urrutia** ([compdani](https://github.com/compdani)) for personal use.

## Pull Requests

**Pull requests will most likely not be merged.** Development follows Danilo's personal needs and available time. A pull request may remain unreviewed or be closed without being merged, even if the change is useful or complete. Please consider this before investing time in a contribution.

## Issues and Feature Requests

**Issues may or may not be fixed.** There is no commitment to respond, investigate, implement requested features, or provide fixes on any schedule. You may report fork-specific problems in [this repository's issue tracker](https://github.com/compdani/actual-pocket/issues), but support is not guaranteed.

The upstream Actual Budget maintainers and community are not responsible for this fork. If you want to contribute to the original project, use its [contributing guide](https://actualbudget.org/docs/contributing/) and follow its policies. Report upstream issues there only when they also occur in the original project.

## Working on Your Own Copy

See the [development setup](packages/docs/docs/contributing/development-setup.md), [code style](packages/docs/docs/contributing/code-style.md), and [testing guide](packages/docs/docs/contributing/testing.md). Run Yarn commands from the repository root. Technical guidance inherited from upstream does not change this fork's contribution policy.

See the [README](README.md#docker-quickstart) for Dockerfile and Docker Compose deployment instructions.
