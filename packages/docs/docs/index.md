Welcome to Actual Pocket's documentation. Actual Pocket is **Danilo Urrutia's personal fork** of [Actual Budget](https://github.com/actualbudget/actual), originally created by James Long and developed by the Actual Budget community.

These guides are inherited from upstream. Links to upstream downloads, hosting providers, communities, and release announcements describe the original project. They do not provide this fork or guarantee support for it.

For deployment of this fork, start with the [Docker guide](./install/docker.md).

## How to Get Around

The left sidebar menu lists the main pages of the documentation. On mobile, it's the collapsed navigation menu icon at the top left. Click on a chevron to view more nested pages on a subject.

The right sidebar of each page lists the outline of the page for quick navigation to a specific subject. On mobile, it's at the top under "On this page".

If you aren't sure where to look for information, an entry in the search bar will show the most useful result at the top, and all results it finds will be available.

## Where to Begin?

If you're new to Actual, consult the [roadmap for new users](./getting-started/roadmap-for-new-users.md).

If you're new to budgeting, read about [envelope budgeting](./getting-started/envelope-budgeting.md).

For help and support, [reach out to the maintainers and community](community/index.md).

## Want to Contribute?

This is a personal fork. **Pull requests will most likely not be merged, and issues may or may not be fixed.** See the [contribution policy](./contributing/index.md) before spending time on a change. Reviews, responses, fixes, and releases are not guaranteed.
